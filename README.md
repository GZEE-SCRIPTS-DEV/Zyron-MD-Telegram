❤️‍🔥 SOBRE O PROJETO

O Zyron-MD Telegram é um bot multifuncional para Telegram desenvolvido pela equipe Gzee Scripts Dev.

O projeto foi desenvolvido como uma base para criação e automação de bots no Telegram, reunindo recursos para interação, administração e personalização.

O objetivo do projeto é oferecer uma estrutura simples, funcional e fácil de modificar, permitindo que novos sistemas e funcionalidades sejam adicionados conforme a necessidade.

🚀 INSTALAÇÃO

📦 Atualizar Pacotes

apt update -y
apt upgrade -y
pkg update -y
pkg upgrade -y

📥 Instalar Dependências

pkg install nodejs -y
pkg install nodejs-lts -y
pkg install ffmpeg -y
pkg install git -y
pkg install wget -y
pkg install tesseract -y

📁 Permitir Storage

termux-setup-storage

📂 Clonar Projeto

git clone https://github.com/GZEE-SCRIPTS-DEV/Zyron-MD-Telegram

📂 Entrar na Pasta

cd Zyron-MD-Telegram

📦 Instalar Módulos

npm install --force --no-bin-links

▶️ Iniciar Bot

npm start

---

⚙️ CONFIGURAÇÃO

Configure os dados do bot de acordo com a estrutura do projeto.

Exemplo:

{
  "Token": "SEU_TOKEN_DO_BOT",
  "NomeBot": "Zyron-MD",
  "NomeIA": "Zyron-AI",
  "Prefix": "$"
}

📋 Campos

Campo| Função
"Token"| Token do bot Telegram
"NomeBot"| Nome do bot
"NomeIA"| Nome da inteligência artificial
"Prefix"| Prefixo dos comandos

«⚠️ Nunca compartilhe o Token do seu bot Telegram. Mantenha suas credenciais privadas e, de preferência, utilize variáveis de ambiente.»

---

🔗 CONECTANDO O BOT

🤖 Telegram BotFather

1. Abra o Telegram
2. Procure pelo @BotFather
3. Inicie uma conversa com o BotFather
4. Utilize o comando "/newbot"
5. Escolha o nome do seu bot
6. Escolha o username do bot
7. Copie o Token gerado
8. Configure o Token no projeto
9. Inicie o bot

Depois execute:

npm start

Se tudo estiver configurado corretamente, o bot ficará online e poderá receber comandos através do Telegram.
